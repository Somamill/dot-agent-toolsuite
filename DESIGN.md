# Design

Editorial field guide inspired by the visual rhythm of Solid's “The Long Hold” article: white canvas, navy type, narrow readable prose and a wide cobalt feature surface. All copy, identity and interface graphics are original; Solid branding and artwork are not reproduced.

Use self-hosted Onest for body and display, IBM Plex Mono only for commands. Maintain a centered 1200px maximum container and a 780px prose measure. Headings are bold, sentence case and generously separated. Primary cobalt is a functional emphasis, not an ambient gradient. No decorative metrics, generic icon-card wall, fake terminal chrome, stock imagery or testimonials.

The main visual is a real workflow selector. Tool catalog entries are compact editorial rows with evidence labels. The learning path is a dated reading sequence. Filters, copy actions and workflow selection have clear keyboard focus, empty states and reduced-motion support. Content remains readable without JavaScript.

All colors and font families live in tokens.css. Accessibility includes contrast, semantic landmarks, real buttons/links, visible focus, 44px control targets and a polite result-count announcement.
