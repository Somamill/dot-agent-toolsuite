# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML, CSS and JavaScript. Node standard-library build and tests. No runtime dependencies or tracking.

## Users
App developers and agent users choosing tools for native, web and creative work.

## Product Purpose
Maintain an experience-led, rated tool library for real app development, backed by a growing learning path. Keep tool availability, a successful command, a small verified operation and production readiness distinct.

## Primary action
Find a tool for a task, inspect its evidence, and open its official source.

## Content and publication
Use reviewed, sanitized findings from the owner's tool setup. Never publish raw chat, credentials, private source, personal paths, screenshots of unrelated applications or private repository inventory. Activity receipts contain only allowlisted tool IDs, operation categories, outcomes, dates and random IDs. Receipt success is process completion, not proof of app quality.

## Ownership
An independent public technical field guide. Technical tooling implementation belongs to Mac Development Tools. This repository does not change the registered dot. product membership or authorize app releases.
